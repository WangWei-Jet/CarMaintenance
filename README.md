## 这份讲义讲什么

核心思路：**先搞懂车为什么会坏，再推导出该做什么保养**。

所有保养项目本质上都在对抗三种消耗：

| 消耗类型 | 涉及部件 | 更换逻辑 |
|---|---|---|
| 油液变质 | 机油、变速箱油、刹车油、防冻液、助力油 | 消耗品 —— 按**时间 + 里程**换 |
| 滤材堵塞 | 机滤、空滤、空调滤、汽油滤 | 消耗品 —— 随油液一起换 |
| 摩擦件磨损 | 刹车片、刹车盘、轮胎、火花塞、皮带 | 磨损件 —— 按**实测余量**换 |

把这两类东西的更换逻辑搞混，是花冤枉钱的主要原因。

## 特色

- **动态原理图解**：四冲程循环、机油循环路径、冷却系统大小循环、制动液压传递、轮胎排水对比，均为内联 SVG 动画，可暂停在任意瞬间观察
- **可交互组件**：刹车片磨损模拟器，拖动滑块即可看到不同厚度对应的判断结论
- **完全离线可用**：无任何外部依赖，单个 HTML 文件即可打开
- **支持打印**：内置打印样式，可直接导出 PDF
- **图表丰富**：14 张原理图解 + 19 张对照表 + 43 个动画元素

## 本地使用

直接双击 `index.html` 用浏览器打开即可，无需任何环境或依赖。

若要把动画版的内容打印成纸质讲义，建议使用 `archive/` 下的静态版备份 —— 动画在打印时会定格在某一帧。

## 免责声明

本讲义为通用性入门培训材料，用于建立保养知识的整体框架与判断逻辑。**具体的保养周期、油液规格、扭矩参数、故障处理方法，请以随车《用户手册》和厂家技术资料为准** —— 不同品牌、不同年款、不同动力形式的车型差异很大。

文中数据为行业常见参考范围，非针对特定车型的技术规格。涉及制动、转向、高压电（新能源车）、安全气囊等系统的拆装作业，请交由具备资质的专业人员进行。
